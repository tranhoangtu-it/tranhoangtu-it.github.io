🧩 Backward-Compatible TDL & XML Envelope (TallyPrime 4.x + Tally.ERP 9 Rel 6.x)

Uses $AlterId watermark filtering + REMOTEID/GUID deduplication so legacy Tally.ERP 9 never locks the UI thread.

<!-- 1. INCREMENTAL PULL REQUEST (Compatible with Tally.ERP 9 Rel 6.x & TallyPrime 3.x/4.x) -->
<ENVELOPE>
  <HEADER>
    <VERSION>1</VERSION>
    <TALLYREQUEST>Export</TALLYREQUEST>
    <TYPE>Collection</TYPE>
    <ID>CloudDeltaVoucherCollection</ID>
  </HEADER>
  <BODY>
    <DESC>
      <STATICVARIABLES>
        <SVEXPORTFORMAT>$$SysName:XML</SVEXPORTFORMAT>
        <SVCURRENTCOMPANY>Apex Manufacturing Pvt Ltd</SVCURRENTCOMPANY>
      </STATICVARIABLES>
      <TDL>
        <TDLMESSAGE>
          <COLLECTION NAME="CloudDeltaVoucherCollection" ISINITIALIZE="Yes">
            <TYPE>Voucher</TYPE>
            <FETCH>GUID, MasterId, AlterId, Date, VoucherTypeName, VoucherNumber, PartyLedgerName, Amount, Reference, AllLedgerEntries.*</FETCH>
            <FILTER>AlterIdWatermarkFilter</FILTER>
          </COLLECTION>
          <SYSTEM TYPE="Formulae" NAME="AlterIdWatermarkFilter">$AlterId &gt; 98410</SYSTEM>
        </TDLMESSAGE>
      </TDL>
    </DESC>
  </BODY>
</ENVELOPE>

📊 Power BI / Excel Power Query (ODBC + Cloud PostgreSQL Read-Replica)

Instead of querying fragile local Tally ODBC ports directly from Excel, all 4 companies sync every 60s into an indexed Cloud PostgreSQL Star Schema (`fact_vouchers`, `dim_company`, `vw_intercompany_recon`). 

// Power BI & Excel Power Query (M Language) — Live Multi-Company Tally Cloud Connector
let
    Source = Odbc.DataSource(
        "Driver={PostgreSQL Unicode(x64)};Server=tally-warehouse.internal.cloud;Port=5432;Database=tally_group_mis;Sslmode=require;",
        [HierarchicalNavigation = true]
    ),
    db = Source{[Name="tally_group_mis", Kind="Database"]}[Data],
    public = db{[Name="public", Kind="Schema"]}[Data],
    ConsolidatedMIS = public{[Name="vw_consolidated_group_vouchers", Kind="View"]}[Data],
    FilteredFY = Table.SelectRows(ConsolidatedMIS, each [fiscal_year] = "FY2026-27" and [is_cancelled] = false)
in
    FilteredFY
